# Crowley's City SEO Playbook

**Crowley’s Granite & Quartz** operating reference for planning, rebuilding, publishing, and measuring city-level countertop pages on [crowleysgranite.com](https://crowleysgranite.com).

## Canonical documents

| Document | Purpose | Use it when |
|---|---|---|
| [City Page Standard](city-page-standard.md) | The governing strategy, rules, decision register, evidence requirements, schema controls, release process, and Tigard pilot plan. | Designing a city page, resolving a publishing question, or changing the template/site-wide configuration. |
| [City Page Build Checklist](city-page-build-checklist.md) | The required pre-publication checklist, split between an existing-page cleanup and a full city-hub rebuild/new launch. | Preparing, reviewing, or approving a live city-page release. |

## Working principle

> A city page must be a useful, truthful local decision page supported by real evidence, not a city-name-swapped template.

## How to use this playbook

1. Start with the **City Page Standard** to identify the correct page state and governing rules.
2. Create the page brief, claims evidence, city fact record, and permission records required for the selected release state.
3. Use the **City Page Build Checklist** before any City Page cleanup, rebuild, or new launch is published.
4. Record the release and measure qualified leads and URL-level search performance at the intervals defined in the standard.
